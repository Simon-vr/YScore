# Publishing this doc folder to GitHub Pages

This `doc/` folder is a self-contained Jekyll site. GitHub Pages builds it
automatically from the `/docs` folder of your repository — no extra toolchain
needed, and you only ever touch/push files inside `doc/`.

## One-time setup (2 steps)

1. **Set `baseurl`** in `doc/_config.yml`:
   - If your site lives at `https://<user>.github.io/<repo>/` (a *project* page,
     the usual case for a repo like `yscore`), set:
     ```yaml
     baseurl: "/<repo>"
     ```
   - If it's a *user/org* page (`https://<user>.github.io/`) or the doc folder
     is the root of its own Pages repo, leave it empty:
     ```yaml
     baseurl: ""
     ```

2. **Turn on Pages** in your repo:
   - GitHub → your repo → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main`, folder: **`/docs`**
   - Save.

## Publishing (every update)

Just commit and push your `doc/` changes to `main`. GitHub Pages rebuilds the
site automatically (usually in under a minute). There's nothing else to run.

## Layout

- **English** is the default at the site root: `/`, `/learn/...`
- **Chinese** lives under `/zh/`, `/zh/learn/...`
- A language toggle is in the top-right of every page.

## Note

- The demo `image/show.mp4` is served as-is; keep it reasonably small (GitHub
  Pages has a 100 MB soft limit per file).
- Internal links, the sidebar and the language switcher are generated by
  `_layouts/default.html`; no plugin is required.
