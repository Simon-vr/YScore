mepc: 保存异常返回地址

mcause: 保存异常原因

mtval: 异常辅助信息

mtvec: 异常处理向量地址

mie: 中断分开关

mie.mtie: 第7位, 时钟使能

### 任务抽象 + 协作式调度

**目标**：实现 2-3 个任务手动 yield 切换。

**小任务拆解**：

1. **Day 1-3**：定义简化 TCB（Task Control Block）：栈指针、任务函数、状态、优先级；静态创建任务（数组或链表）。
2. **Day 3-5**：实现任务栈初始化（在栈底伪造上下文，让第一次切换能“返回”到任务函数）。
3. **Day 5-8**：写汇编上下文切换函数（`taskYIELD` → 保存当前任务 sp → 加载下一个任务 sp）。
4. **Day 8-10**：实现 Idle 任务 + 简单就绪表（数组，按优先级找最高就绪任务）。
5. **Day 10-12**：测试 2 个打印不同字符串的任务交替运行。

### 抢占式调度 + SysTick 驱动

**目标**：定时器中断驱动优先级抢占。

**小任务拆解**：

1. **Day 1-3**：在定时器 ISR 中调用调度器，检查是否有更高优先级任务。
2. **Day 3-5**：实现 PendSV-like 机制（RISC-V 常用 software interrupt 或直接在 timer ISR 尾部切换）。
3. **Day 5-8**：添加任务状态（Ready/Blocked/Running）、`vTaskDelay`（用 tick 计数阻塞）。
4. **Day 8-10**：实现调度器启动 `vTaskStartScheduler`（设置第一个任务，开启中断）。
5. **Day 10-12**：测试高优先级任务抢占低优先级 + 延时唤醒。
