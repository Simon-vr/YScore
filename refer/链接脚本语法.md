# 一、先搞懂：.ld 是干嘛的？

**链接脚本（Linker Script）= 告诉链接器（ld）怎么把 .o 文件拼成最终可执行文件**
核心作用只有 3 个：

1. **划分内存**：Flash / RAM 地址、大小
2. **分配段**：代码放哪、数据放哪、栈堆放哪
3. **指定入口**：程序从哪一行开始运行

适用场景：

- 单片机（STM32、ESP32、ARM）
- 裸机程序、Bootloader
- 操作系统内核、底层驱动
- 无操作系统的嵌入式程序

**不写 .ld → 链接器不知道代码放哪 → 直接报错！**

# 二、链接脚本核心指令（小白必背）

所有指令**大小写不敏感**，但习惯大写。

## 1. 内存定义：MEMORY

**作用**：告诉链接器有哪些内存区域（Flash、RAM 等）

```ld
MEMORY
{
  名字 (属性) : ORIGIN = 起始地址, LENGTH = 大小
}
```

属性：

- `r` 只读
- `w` 可写
- `x` 可执行
- `a` 可加载
- `i` 初始化

最常用组合：

- Flash：`rx`
- RAM：`rw`

---

## 2. 段定义：SECTIONS

**作用**：把代码、数据放到指定内存

```ld
SECTIONS
{
  段名 :
  {
    内容（哪些文件放进来）
  } > 内存区域
}
```

---

## 3. 入口点：ENTRY

**作用**：程序从哪个函数开始执行

```ld
ENTRY(Reset_Handler)   # 单片机最常用
```

---

## 4. 变量定义

**作用**：定义栈大小、堆大小、程序起始地址

```ld
_estack = ORIGIN(RAM) + LENGTH(RAM);  /* 栈顶 */
_Min_Stack_Size = 0x200;             /* 最小栈 */
_Min_Heap_Size = 0x200;              /* 最小堆 */
```

---

## 5. 常见段名含义（必须认识）

| 段名            | 内容             | 存放位置 |
| --------------- | ---------------- | -------- |
| `.isr_vector` | 中断向量表       | Flash    |
| `.text`       | 程序代码         | Flash    |
| `.rodata`     | 常量（const）    | Flash    |
| `.data`       | 已初始化全局变量 | RAM      |
| `.bss`        | 未初始化全局变量 | RAM      |
| `.heap`       | 堆               | RAM      |
| `.stack`      | 栈               | RAM      |

# 三、最小可用链接脚本（最简单能跑版本）

**小白第一步：先看懂、能使用这个最小脚本**

## 最小脚本：minimal.ld

```ld
/* 最小链接脚本：适用于 ARM Cortex-M 单片机 */
ENTRY(Reset_Handler)

/* 内存布局 */
MEMORY
{
  FLASH (rx) : ORIGIN = 0x08000000, LENGTH = 128K
  RAM   (rw) : ORIGIN = 0x20000000, LENGTH = 20K
}

/* 段分配 */
SECTIONS
{
  /* 中断向量表 */
  .isr_vector :
  {
    . = ALIGN(4);
    *(.isr_vector)
  } > FLASH

  /* 代码段 */
  .text :
  {
    . = ALIGN(4);
    *(.text)        /* 程序代码 */
    *(.rodata)      /* 常量 */
  } > FLASH

  /* 已初始化数据 */
  .data :
  {
    . = ALIGN(4);
    _sdata = .;
    *(.data)
    _edata = .;
  } > RAM AT > FLASH

  /* 未初始化数据 */
  .bss :
  {
    . = ALIGN(4);
    _sbss = .;
    *(.bss)
    *(COMMON)
    _ebss = .;
  } > RAM

  /* 栈顶指向 RAM 末尾 */
  _estack = ORIGIN(RAM) + LENGTH(RAM);
}
```

## 这是干啥的？

- 代码放 `0x08000000` Flash
- 变量放 `0x20000000` RAM
- 自动放代码、常量、全局变量
- 能直接在 STM32 上跑

# 场景 1：标准嵌入式项目（最常用）

## 文件夹结构

```
project/
├── src/
│   ├── main.c
│   └── startup.s   /* 中断向量 */
├── ld/
│   └── stm32.ld    /* 标准链接脚本 */
└── Makefile
```

## 链接脚本：stm32.ld

```ld
ENTRY(Reset_Handler)

MEMORY
{
  FLASH (rx) : ORIGIN = 0x08000000, LENGTH = 512K
  RAM   (rw) : ORIGIN = 0x20000000, LENGTH = 128K
}

_Stack_Size = 0x400;
_Heap_Size  = 0x200;

SECTIONS
{
  .isr_vector :
  {
    . = ALIGN(4);
    *(.isr_vector)
  } > FLASH

  .text :
  {
    . = ALIGN(4);
    *(.text)
    *(.text.*)
    *(.rodata)
    *(.rodata.*)
  } > FLASH

  _sidata = LOADADDR(.data);

  .data :
  {
    . = ALIGN(4);
    _sdata = .;
    *(.data)
    *(.data.*)
    _edata = .;
  } > RAM AT > FLASH

  .bss :
  {
    . = ALIGN(4);
    _sbss = .;
    *(.bss)
    *(.bss.*)
    *(COMMON)
    _ebss = .;
  } > RAM

  .heap :
  {
    . = ALIGN(8);
    _sheap = .;
    . += _Heap_Size;
    _eheap = .;
  } > RAM

  .stack :
  {
    . = ALIGN(8);
    . += _Stack_Size;
  } > RAM

  _estack = ORIGIN(RAM) + LENGTH(RAM);
}
```

# 场景 2：无操作系统裸机小程序（极简）

## 脚本：baremetal.ld

```ld
ENTRY(_start)

MEMORY
{
  ROM (rx) : ORIGIN = 0x00000000, LENGTH = 64K
  RAM (rw) : ORIGIN = 0x40000000, LENGTH = 16K
}

SECTIONS
{
  .text :
  {
    *(.text)
  } > ROM

  .data :
  {
    *(.data)
  } > RAM AT > ROM

  .bss :
  {
    *(.bss)
  } > RAM
}
```

# 场景 3：带分区、Bootloader + App 双区域（高级实用）

## 脚本：boot_app.ld

```ld
ENTRY(Reset_Handler)

MEMORY
{
  BOOT (rx)  : ORIGIN = 0x08000000, LENGTH = 32K
  APP  (rx)  : ORIGIN = 0x08008000, LENGTH = 224K
  RAM  (rw)  : ORIGIN = 0x20000000, LENGTH = 20K
}

SECTIONS
{
  .isr_vector :
  {
    *(.isr_vector)
  } > APP

  .text :
  {
    *(.text)
    *(.rodata)
  } > APP

  .data :
  {
    *(.data)
  } > RAM AT > APP

  .bss :
  {
    *(.bss)
  } > RAM
}
```

# 五、小白最常用的 10 条语法（速查）

```ld
ENTRY(函数名)          设置程序入口
MEMORY { ... }         定义内存区域
. = ALIGN(4);          4 字节对齐（必须加）
*(.text)               所有文件的代码段
_sdata = .;            定义一个变量，记录当前地址
> FLASH                放到 FLASH
> RAM AT > FLASH       运行在 RAM，加载在 FLASH
. += 0x200;            向后偏移 0x200
_estack = ...          栈顶地址
INCLUDE filename       包含其他 ld 文件
```

# 六、如何使用 .ld 脚本？

## 方法 1：GCC 编译时指定

```bash
arm-none-eabi-gcc -T myscript.ld main.c -o app.elf
```

## 方法 2：CMake 中指定

```cmake
set(LINKER_SCRIPT ${CMAKE_SOURCE_DIR}/stm32.ld)
target_link_options(app PRIVATE -T ${LINKER_SCRIPT})
```

## 方法 3：Makefile 中指定

```makefile
LDFLAGS += -T stm32.ld
```

# 七、小白常见错误（一看就懂）

- `undefined reference to _estack` → 没定义栈顶
- `could not allocate section` → 内存超了
- `section .text overlaps` → 段冲突
- `wrong alignment` → 缺 `. = ALIGN(4);`
