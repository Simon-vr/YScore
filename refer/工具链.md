# brew install riscv-tools（macOS riscv/riscv 源）完整工具清单

`riscv-tools` 是**元包（metapackage）**，本身不提供工具，会自动安装下面3个核心组件 + 依赖工具：
`riscv-gnu-toolchain`、`riscv-isa-sim(spike模拟器)`、`riscv-pk(代理内核/bbl)`、dtc设备树编译器

---

## 一、完整包含的二进制工具（命令）

前缀统一：**riscv64-unknown-elf-***（裸机ELF交叉工具链）

### 1. GNU Binutils 二进制工具集

- `riscv64-unknown-elf-as`：汇编器
- `riscv64-unknown-elf-ld`：链接器
- `riscv64-unknown-elf-ar`：静态库打包
- `riscv64-unknown-elf-objdump`：反汇编/查看ELF
- `riscv64-unknown-elf-readelf`：ELF解析
- `riscv64-unknown-elf-nm`：符号查看
- `riscv64-unknown-elf-strip`：符号剥离

### 2. GCC 交叉编译器（C/C++）

- `riscv64-unknown-elf-gcc`：C编译器
- `riscv64-unknown-elf-g++`：C++编译器
- 配套：newlib裸机标准库、libgloss

> 默认**不带GDB**（编译时禁用gdb）

### 3. Spike 官方模拟器（riscv-isa-sim）

- `spike`：RISC-V ISA指令级模拟器（官方参考模拟器）
- `spike-dasm`：配套反汇编

### 4. riscv-pk（Proxy Kernel / BBL）

- `pk`：裸机程序代理、bootloader、物理内存管理、中断处理
- 配合spike运行用户态裸机程序

### 5. 依赖工具

- `dtc`：Device Tree Compiler 设备树编译工具

---

## 二、**不包含**的工具（需要单独安装）

1. **riscv-gdb**：调试器（默认不装）

```bash
brew install riscv-elf-gdb
```

2. **OpenOCD JTAG调试**：硬件调试下载器

```bash
brew install riscv-openocd
```

3. **QEMU模拟器**：全系统模拟器（和spike二选一）

```bash
brew install qemu
```
