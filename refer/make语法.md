# Makefile 完整详细语法整理

完全按照**标准 GNU Make** 语法，只讲规则、定义、关键字、符号、原理，不附带代码示例。

---

## 一、整体结构与核心规则语法

### 1. 基本规则格式（最核心）

```
目标: 依赖列表
	命令序列
```

语法严格要求：

1. 冒号分隔**目标**与**依赖**
2. 命令行**必须以 Tab 字符开头**，不能是空格
3. 依赖可以为空；命令可以为空
4. Make 会自动比较**目标文件修改时间**与依赖修改时间：
   依赖比目标新 → 重新执行命令；否则跳过

### 2. 规则执行逻辑

1. 首先查找**默认第一个规则**作为最终目标
2. 递归检查所有依赖是否需要重建
3. 依赖全部就绪后，自上而下执行对应命令
4. 命令返回非0 → Make 立即终止报错

## 二、变量语法

### 1. 变量定义方式

1. 简单赋值（立即展开）

```makefile
VAR = 内容
```

赋值时**不展开变量**，使用时才展开

2. 立即赋值（延时展开关闭）

```makefile
VAR := 内容
```

定义时**立刻完全展开**，后续修改不影响已定义值

3. 追加赋值

```makefile
VAR += 新增内容
```

在原有内容后追加，自动加空格分隔

4. 条件赋值（未定义才赋值）

```makefile
VAR ?= 默认值
```

变量不存在/为空时才赋值，已定义则忽略

### 2. 变量使用语法

```
$(变量名)
${变量名}
```

两种括号完全等价。

### 3. 内置自动变量（预定义，不可修改）

- `$@`：当前规则的**目标文件**
- `$<`：当前规则的**第一个依赖文件**
- `$^`：当前规则**所有不重复依赖文件**合集
- `$+`：当前规则**所有依赖（重复保留）**合集
- `$?`：比目标文件**新的依赖文件**列表

### 4. 环境变量

系统环境变量会自动导入 Makefile；
Makefile 内定义的变量会覆盖同名环境变量。

## 三、伪目标 .PHONY 语法

### 语法

```makefile
.PHONY: 目标1 目标2 ...
```

作用：
声明该目标**不是磁盘文件**，只是命令标签。

效果：

1. 即使当前目录存在同名文件，也会强制执行命令
2. 不会检查时间戳，永远执行
3. 常见：clean、all、install、run、dump

---

## 四、条件判断语法

四种关键字：

```makefile
ifeq (A,B)      # A等于B成立
ifneq (A,B)     # A不等于B成立
ifdef VAR       # 变量已定义非空
ifndef VAR      # 变量未定义/为空
endif           # 结束条件块
```

结构固定：

```
条件关键字
	语句
endif
```

---

## 五、函数语法

格式：

```
$(函数名 参数1,参数2,...)
```

参数用逗号分隔，空格会被当作参数一部分。

常用内置函数分类：

1. 字符串处理：subst、patsubst、strip、findstring
2. 文件路径处理：dir、notdir、suffix、basename、addsuffix、addprefix
3. 遍历替换：wildcard（获取当前目录文件列表）

---

## 六、注释、换行、续行语法

1. 注释：`#` 后面整行都是注释，从#开始到行尾
2. 命令换行续行：行尾加反斜杠 `\`
3. 变量换行续行：同样行尾 `\`
4. 空行会被忽略

---

## 七、VPATH 搜索路径语法

```makefile
VPATH = 目录1:目录2:目录3
```

作用：
Make 在当前目录找不到依赖文件时，自动去 VPATH 目录查找。

---

## 八、隐式规则（内置默认规则）

GNU Make 自带内置隐含规则，无需手写：

- `.c` → `.o` 自动用 cc 编译
- `.s`/`.S` → `.o` 自动用汇编器汇编
- `.o` 链接可执行文件

可以通过 `MAKEFLAGS` 或变量关闭隐式规则。

---

## 九、命令执行细节语法规则

1. 每行命令单独开 shell 执行，互不继承变量
2. 命令前加 `@`：**不打印命令本身，只执行**
3. 命令前加 `-`：命令出错**忽略错误，继续执行**
4. 多行命令用分号分隔可写在同一行

---

## 十、执行 Make 的命令行语法

```bash
make 目标          # 指定目标执行
make -jN           # N线程并行编译
make -B            # 强制全部重新编译
make -C 目录       # 进入指定目录读取Makefile
make -f 文件名     # 使用指定文件作为Makefile
```

---

## 十一、完整语法总结（精简背诵版）

1. 规则：`目标:依赖` + Tab命令
2. 变量：`=`、`:=`、`+=`、`?=`，使用 `$(var)`
3. 自动变量：$@ $< $^
4. 伪目标：`.PHONY`
5. 条件：ifeq/ifneq/ifdef/ifndef/endif
6. 函数：$(func param)
7. 注释#、续行\、静默@、忽略错误-
8. VPATH 搜索路径
9. make 命令参数：-j -B -C -f
