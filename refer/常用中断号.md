# 异常号（mcause/scause 最高位=0）

| 编号 | 名称                           | 说明                    |
| ---- | ------------------------------ | ----------------------- |
| 0    | Instruction address misaligned | 指令地址未对齐          |
| 1    | Instruction access fault       | 取指访问错误            |
| 2    | Illegal instruction            | 非法指令                |
| 3    | Breakpoint                     | 断点异常（EBREAK）      |
| 4    | Load address misaligned        | 加载地址未对齐          |
| 5    | Load access fault              | 加载访问错误            |
| 6    | Store/AMO address misaligned   | 存储/原子操作地址未对齐 |
| 7    | Store/AMO access fault         | 存储/原子操作访问错误   |
| 8    | Environment call from U-mode   | U 态系统调用            |
| 9    | Environment call from S-mode   | S 态系统调用            |
| 11   | Environment call from M-mode   | M 态系统调用            |

# 中断号（mcause/scause 最高位=1）

| 编号 | 名称                                | 说明           |
| ---- | ----------------------------------- | -------------- |
| 1    | Supervisor software interrupt (SSI) | S 态软件中断   |
| 3    | Machine software interrupt (MSI)    | M 态软件中断   |
| 5    | Supervisor timer interrupt (STI)    | S 态定时器中断 |
| 7    | Machine timer interrupt (MTI)       | M 态定时器中断 |
| 9    | Supervisor external interrupt (SEI) | S 态外部中断   |
| 11   | Machine external interrupt (MEI)    | M 态外部中断   |
