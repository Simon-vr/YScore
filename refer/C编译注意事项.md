# 一、GCC 编译 C 语言，**自动生成 4 个段**（固定名字，不能乱改）

你的 C 代码一编译，GCC **自动把内容分类塞进这 4 个段**：

## 1. **`.text` —— 代码段（函数、指令）**

放：

- 所有函数体
- if/for/while 编译后的指令

特点：

- 只读、可执行
- 链接脚本必须包含 `*(.text .text*)`

## 2. **`.rodata` —— 只读常量**

放：

- `const` 全局变量
- 字符串常量 `"hello"`

特点：

- 只读
- 不能修改

## 3. **`.data` —— 已初始化全局/静态变量**

放：

```c
int a = 10;
static int b = 20;
```

特点：

- 程序运行前就有值
- 需要从 Flash 拷贝到 RAM

## 4. **`.bss` —— 未初始化全局/静态变量**

放：

```c
int a;
static int b;
```

特点：

- 默认为 0
- **不占用 ELF 文件空间**
- 运行时必须**手动清零**（你的启动汇编要做）

# 二、GCC **函数与变量的符号规则**（C ↔ 汇编 互通关键）

## 1. **C 函数名 → 汇编里就是同名符号**

C：

```c
void my_func() { ... }
```

汇编里可以直接：

```asm
call my_func
```

## 2. **汇编要让 C 调用，必须加 `.global`**

```asm
.global my_func   # 导出符号
my_func:
    ret
```

## 3. **C 调用汇编函数，只需要声明**

```c
void my_func(void);
```

# 三、**裸机 C 开发最重要的 3 个隐藏规则**（99% 的人踩坑）

## 规则 1：**C 语言默认依赖 crt0，裸机必须关闭！**

正常 Linux 程序：

- GCC 自动链接 crt0.o
- 自动设置栈
- 自动清 bss

**裸机 = 绝对不能用 crt0！**
所以编译必须加：

```
-nostartfiles -nostdlib -ffreestanding
```

作用：

- 不链接启动文件
- 不链接标准库
- 不假设任何运行环境

## 规则 2：**C 语言运行前，必须由汇编做 2 件事**

1. **设置栈指针 `sp`**
   没有栈，C 直接崩溃
2. **清零 `.bss` 段**
   不然全局变量是随机值

你的 `start.S` 必须干这两件事！

## 规则 3：**入口地址不是 main，是 `_start`**

- `_start` 是汇编写的
- `_start` 调用 `main`
- 链接脚本必须写：

```ld
ENTRY(_start);
```

# 四、**变量存储位置规则（超级重要）**

| C 代码            | 段      | 初始化 | 是否占文件空间 |
| ----------------- | ------- | ------ | -------------- |
| `int a = 5`     | .data   | 是     | 占             |
| `int a;`        | .bss    | 0      | 不占           |
| `const int a=5` | .rodata | 是     | 占             |
| 局部变量`int a` | 栈      | 随机   | 不占           |

---

# 五、**链接脚本必须包含的段**

你必须在 ld 脚本里写：

```ld
.text : { *(.text .text*) }
.rodata : { *(.rodata .rodata*) }
.data : { *(.data .data*) }
.bss : { *(.bss .bss*) }
```

这就是**收纳所有 C 编译出来的段**。

# 六、**Makefile 里 C 编译参数的意义（你必须理解）**

```makefile
CFLAGS = -march=rv32i \
         -mabi=ilp32 \
         -O0 \
         -g \
         -nostartfiles \
         -nostdlib \
         -ffreestanding
```

含义：

- `-march=rv32i`：只生成 RV32I 指令
- `-mabi=ilp32`：32 位 int/long/pointer
- `-O0`：不优化，方便调试
- `-g`：带调试信息
- `-nostartfiles`：**不使用 crt0**
- `-nostdlib`：**不使用标准库**
- `-ffreestanding`：**独立环境（裸机必加）**

---

# 七、**最精简总结（你背这 6 条就够）**

1. **C 自动生成 .text / .rodata / .data / .bss**
2. **汇编必须提供 _start 入口**
3. **_start 必须设置 sp + 清 bss**
4. **裸机必须加 -nostartfiles -nostdlib**
5. **汇编函数用 .global 导出，C 声明后可调用**
6. **链接脚本负责收纳所有段**
