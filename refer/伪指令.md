# RISC-V 伪指令大全 + 核心结论

我给你整理**最常用、最实用**的 RISC-V 伪指令，一次性讲清楚：
**哪些是伪指令、它们对应什么真实指令、是不是 RISC-V 专用**。

---

# 一、核心结论（先记住这个）

1. **伪指令 = 汇编器提供的“简写语法糖”**
   CPU 硬件**不直接识别**，汇编时会翻译成真实指令。
2. **你问的 la / li 以及下面所有伪指令，都是 RISC-V 专用的！**
   不是 x86 / ARM / 通用汇编，**只属于 RISC-V**。
3. 它们依赖 **RV32I / RV64I 基础指令集**实现。

---

# 二、RISC-V 最常用伪指令一览表（必须背）

## 1. 数据加载类

| 伪指令           | 含义       | 翻译成真实指令             |
| ---------------- | ---------- | -------------------------- |
| `li rd, imm`   | 加载立即数 | `lui + addi` 或 `addi` |
| `la rd, label` | 加载地址   | `auipc + addi`           |
| `mv rd, rs`    | 寄存器复制 | `addi rd, rs, 0`         |

## 2. 跳转与分支类

| 伪指令             | 含义               | 翻译成真实指令        |
| ------------------ | ------------------ | --------------------- |
| `j label`        | 无条件跳转         | `jal x0, label`     |
| `jal label`      | 跳转并保存返回地址 | 真实指令（J-type）    |
| `ret`            | 函数返回           | `jalr x0, x1, 0`    |
| `beqz rs, label` | 等于0跳转          | `beq rs, x0, label` |
| `bnez rs, label` | 不等于0跳转        | `bne rs, x0, label` |
| `blez rs, label` | 小于等于0跳转      | 组合指令              |
| `bgtz rs, label` | 大于0跳转          | 组合指令              |

## 3. 栈操作与函数调用

| 伪指令         | 含义                   | 翻译成真实指令       |
| -------------- | ---------------------- | -------------------- |
| `push regs`  | 压栈（部分汇编器支持） | `sw`/`sd` + 减法 |
| `pop regs`   | 弹栈                   | `lw`/`ld` + 加法 |
| `call label` | 函数调用               | `auipc + jalr`     |

## 4. 清零与空操作

| 伪指令         | 含义     | 翻译成真实指令      |
| -------------- | -------- | ------------------- |
| `nop`        | 空操作   | `addi x0, x0, 0`  |
| `not rd, rs` | 按位取反 | `xori rd, rs, -1` |
| `neg rd, rs` | 取负数   | `sub rd, x0, rs`  |

---

# 三、这些伪指令是 RISC-V 专用还是通用？

## **100% 是 RISC-V 专用！**

- x86 没有 `li / la / mv / ret / j` 这种伪指令写法
- ARM 也没有
- 每一种 CPU 的伪指令都不一样
- **伪指令由汇编器定义，不是跨平台通用的**

---

# 四、最常用的 8 个必须记住

```
mv   rd, rs      # 复制寄存器
li   rd, imm     # 加载立即数
la   rd, label   # 加载地址
j    label       # 无条件跳转
ret              # 函数返回
nop              # 空指令
not  rd, rs      # 取反
neg  rd, rs      # 取负
```

---

# 五、一句话总结

1. **伪指令不是硬件指令，是汇编器简写**
2. **la / li / mv / j / ret 等全部是 RISC-V 专用**
3. 最终都会翻译成：`addi` / `lui` / `auipc` / `jal` / `jalr` / `beq` 等真实指令
