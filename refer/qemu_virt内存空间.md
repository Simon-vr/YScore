下面给你 **QEMU RISC-V virt 平台最完整、最权威、可直接写进链接脚本的物理内存空间布局**（来自 QEMU 源码 `hw/riscv/virt.c`）。

---

## 一、核心总览（一句话记死）

- **CPU 复位强制从 `0x80000000` 取指执行**（不可改）
- **`0x00000000 ~ 0x0000FFFF` 是 QEMU 内置 MROM（只读 Boot ROM）**，**你不能放代码**
- **你的所有代码、数据、栈必须放在 `0x80000000` 开始的 DRAM（可读写 RAM）**

---

## 二、完整物理地址空间（按地址从低到高）

### 1. 低地址区（0x0 ~ 0x7FFFFFFF）：设备与ROM（只读/MMIO）

| 地址范围                    | 名称                       | 大小  | 用途                      | 权限 |
| --------------------------- | -------------------------- | ----- | ------------------------- | ---- |
| `0x00000000 ~ 0x000000FF` | VIRT_DEBUG                 | 256B  | 调试寄存器                | 只读 |
| `0x00001000 ~ 0x0000FFFF` | **MROM（Boot ROM）** | 60KB  | QEMU 内置启动固件（只读） | 只读 |
| `0x00100000 ~ 0x00100FFF` | VIRT_TEST                  | 4KB   | 测试/看门狗               | MMIO |
| `0x00101000 ~ 0x00101FFF` | RTC                        | 4KB   | 实时时钟                  | MMIO |
| `0x02000000 ~ 0x0200FFFF` | **CLINT**            | 64KB  | 核本地中断/定时器         | MMIO |
| `0x03000000 ~ 0x0300FFFF` | PCIE_PIO                   | 64KB  | PCI 端口 I/O              | MMIO |
| `0x0C000000 ~ 0x0FFFFFFF` | **PLIC**             | 64MB  | 平台级中断控制器          | MMIO |
| `0x10000000 ~ 0x100000FF` | **UART0**            | 256B  | 串口（ttyS0）             | MMIO |
| `0x10001000 ~ 0x10001FFF` | **VirtIO 块/网**     | 4KB   | 虚拟磁盘/网卡             | MMIO |
| `0x20000000 ~ 0x23FFFFFF` | FLASH                      | 64MB  | 虚拟 Flash（可写）        | 读写 |
| `0x30000000 ~ 0x3FFFFFFF` | PCIE_ECAM                  | 256MB | PCIe 配置空间             | MMIO |
| `0x40000000 ~ 0x7FFFFFFF` | PCIE_MMIO                  | 1GB   | PCIe 设备映射             | MMIO |

---

### 2. 高地址区（0x80000000 ~ ...）：**你的可用 DRAM（RAM）**

- **基地址：`0x80000000`**（CPU 复位入口）
- **默认大小：128MB → 范围 `0x80000000 ~ 0x88000000`**
- 可通过 QEMU 命令行 `-m 512M` 等扩大
- **权限：可读、可写、可执行（RXW）**
- **你的代码、数据、栈、堆全部放这里**

---

## 三、最关键的 3 个地址（必须背）

1. **`0x80000000`**
   - CPU 上电/复位后**第一条指令地址**
   - 你的启动代码（`_start`）**必须放在这里**
2. **`0x00001000`**
   - QEMU 内置 Boot ROM（只读）
   - 跳去这里只会执行 QEMU 代码，**不是你的**
3. **`0x10000000`**
   - UART0 串口地址（打印用）

---

## 四、启动流程（硬件级）

1. CPU 复位 → PC = `0x80000000`
2. 执行你放在 `0x80000000` 的第一条指令
3. 正常执行你的启动代码、内核

---

## 五、链接脚本写法（直接抄）

```ld
MEMORY
{
    /* 唯一可用的 RAM：0x80000000 开始，默认 128MB */
    ram (rxw) : ORIGIN = 0x80000000, LENGTH = 128M
}

SECTIONS
{
    . = 0x80000000;

    .text : {
        *(.text.startup)   /* 启动代码必须放最前面 */
        *(.text*)
    } > ram

    .rodata : {
        *(.rodata*)
    } > ram

    .data : {
        *(.data*)
    } > ram

    .bss : {
        *(.bss*)
        *(COMMON)
    } > ram
}
```

## 六、常见误区澄清

- ❌ 误区：“我可以把代码放 `0x00000000`”
  ✅ 真相：`0x00000000 ~ 0x0000FFFF` 是**只读 MROM**，你**不能写、不能放代码**
- ❌ 误区：“ENTRY(_start) 能改启动地址”
  ✅ 真相：ENTRY 只标记调试入口，**CPU 只认 `0x80000000`**
- ❌ 误区：“我可以跳去 `0x00000000` 执行自己代码”
  ✅ 真相：跳去只会执行 QEMU 固件，**不是你的代码**

## 七、一句话总结

**QEMU RISC-V virt 只有 `0x80000000` 开始的 DRAM 是你的地盘，其他都是设备/ROM。**
