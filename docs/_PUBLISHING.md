# Publishing this folder to GitHub Pages

This `docs/` folder is a self-contained Jekyll site. GitHub Pages builds it
automatically from the `/docs` folder of your repository — no extra toolchain
needed, and you only ever touch/push files inside `docs/`.

Your site: **https://Simon-vr.github.io/YScore/**

- English (default): `https://Simon-vr.github.io/YScore/` and `/learn/...`
- Chinese: `https://Simon-vr.github.io/YScore/zh/` and `/zh/learn/...`

`baseurl` is already set to `/YScore` in `docs/_config.yml` and must match the
repo name (case-sensitive).

## One-time setup (2 steps)

1. **`baseurl`** — already done: `baseurl: "/YScore"`. If you ever rename the
   repo, update it to `/<NewName>`.

2. **Turn on Pages** in your repo:
   - GitHub → `Simon-vr/YScore` → **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main`, folder: **`/docs`**
   - Save.

## Publishing (every update)

```bash
git add docs/ && git commit -m "update docs" && git push origin main
```

GitHub Pages rebuilds automatically (usually < 1 minute). Nothing else to run.

## Layout

- **English** is the default at the site root: `/`, `/learn/...`
- **Chinese** lives under `/zh/`, `/zh/learn/...`
- A language toggle is in the top-right of every page.

## Note

- The demo `image/show.mp4` is served as-is; keep it reasonably small (GitHub
  Pages has a 100 MB soft limit per file).
- Internal links, the sidebar and the language switcher are generated by
  `_layouts/default.html`; no plugin is required.
